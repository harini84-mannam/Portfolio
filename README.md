**Features:**

* Document edge detection
* Perspective correction
* Shadow removal
* Image denoising
* Tesseract OCR
* Document classification
* Offline extractive text summarization

**Technologies:** Python, Flask, OpenCV, Tesseract OCR

### 2. AI Resume Screening System

A Flask-based resume screening application that ranks resumes against a given job description.

**Features:**

* PDF and image resume processing
* OCR for scanned resumes
* OpenCV preprocessing
* Structured resume information extraction
* TF-IDF and cosine similarity matching
* Candidate ranking and shortlisting
* CSV export

**Technologies:** Python, Flask, OpenCV, Tesseract OCR, NumPy

## 🚀 Running the Portfolio Locally

Since this is a static HTML/CSS website, no backend setup is required.

### 1. Clone the repository

```bash
git clone https://github.com/harini84-mannam/YOUR-REPOSITORY-NAME.git
```

### 2. Open the project

```bash
cd YOUR-REPOSITORY-NAME
```

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
